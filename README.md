# Phigros C89 Controller

一款专为节奏游戏《Phigros》设计的第八章与第九章进度管理与回退控制工具。

通过登录 TapTap 账号换取授权，读取并解析官方云存档数据，以响应式时间轴的形式直观展示并调节游戏剧情节点的解锁进度。

## 功能特性

- **直观的双向时间轴**：支持横向（宽屏交错）与竖向（自下而上递增）进度展示，清晰浏览各关键节点的解锁状态。
- **第九章完整双阶段控制**：
  - **表层（Phase 1）**：包含入场、About The Universe、分支双曲、Entrance to the Chaos 直至隐藏曲密码输入环节。
  - **里层（Phase 2）**：包含 Rework 重演、Ametrine、Petrichor 挑战、基准测试及最终通关全链路。
- **合法性与前置依赖约束**：
  - 进度受严格的单向依赖拓扑保护：未完成第八章时禁止进入第九章；倒退第八章时会联动清空第九章状态，防止生成不合法的异常存档。
  - 倒退阶段自动重置生命值档位与密码凭据等非布尔量。
- **安全密码凭据机制**：
  - 隐藏曲解锁密码完全由玩家通过游戏流程自行解密获得，应用不内嵌、不预设、不泄露密码明文。
  - 支持未上传前的进度自由撤回与重调；一旦倒退并成功同步至云端，内存密码即刻销毁，确保云端数据一致性。
- **本地备份与防冲突保护**：
  - 每次读取云存档自动在本地创建加密备份，支持一键恢复（本地恢复免二次输密）。
  - 上传前自动校验云端时间戳与 summary 校验和，检测到冲突时提供明细比对界面，避免误覆盖更新的存档。
- **多账号无缝切换**：支持保存多个 TapTap 授权，实现多用户相互隔离的独立管理。

## 使用指南

1. **登录授权**：启动应用后点击“使用 TapTap 登录”，在弹出的系统浏览器中完成官方 OAuth 授权回调。
2. **选择章节**：进入控制台主界面，通过顶部标签切换第八章或第九章。
3. **调整进度**：
   - 点击时间轴上的目标节点将进度调整至对应状态。
   - 若选择涉及隐藏曲及后续阶段，按照提示输入您在游戏内获取的正确密码。
4. **保存与上传**：确认节点调整无误后，点击右下角的“保存并上传”浮动按钮，将变更提交至 TapTap 官方云端。
5. **在游戏中生效**：启动 Phigros，在游戏设置内点击“同步云存档”，下载云端最新存档即可畅玩对应节点。
