# Phigros C89 Controller

非官方 Phigros 第八章、第九章进度管理工具。第九章包含「表层」和「里层」，通过时间轴调整云存档中的章节进度。

> **修改存档有风险。** 请先在游戏内上传并确认备份，操作期间关闭游戏，避免双端覆盖。当前解析规则针对 Phigros **4.0.1（build 157）/ gameProgress v6**，不保证兼容其他版本。

## 下载与平台

在本仓库 [Releases](https://github.com/PhigrosLabs/Phigros-C89-Controller/releases) 获取已发布版本；没有 Release 时表示尚未完成发布验证。

目标平台为 Android、Windows、Linux、macOS 和 iOS，不支持 Web。桌面压缩包需完整解压，不能仅复制可执行文件。iOS 构建为未签名 Runner.app，需自行签名才能安装；macOS 产物未经 Apple 公证。
Android 使用默认 debug 密钥签名，仅供测试和研究；不同构建环境生成的默认密钥可能不同，无法保证跨版本覆盖安装。不要在没有备份的情况下卸载旧版本。

## 使用

1. 通过浏览器完成 TapTap 登录，选择需要操作的账号。
2. 等待读取云存档并自动创建本地加密备份。
3. 切换第八章/第九章，点击时间轴节点或调整进度。宽屏横向展示，竖屏自下向上递增。
4. 调整仅为草稿，点击「保存并上传」才写入云端。若云端出现较新存档，请核对冲突提示后再选择。
5. 在游戏中下载修改后的云存档，检查进度；如有问题，通过设置中的本地备份恢复。

隐藏曲密码必须由玩家自行在游戏内获取，应用不提供答案。本地备份解密不需要输入隐藏曲密码。倒退后尚未上传时可复用本次输入；倒退至密码前并上传成功后，再次前进需要重新输入。

## 已知限制

- 不修改成绩、不重新计算 RKS；上传保留原 summary。
- 云存档不能完整重建游戏本地的 Message 退出/重启接续状态。
- 当前正核查「输入密码」到「表层通关」的游戏内入口反馈问题；在修复并完成实机验证前，建议避免依赖该节点重演流程，保留真实备份。
- 多语言与各平台完整实机兼容性仍需验收，不将构建成功视为全部功能验证通过。
